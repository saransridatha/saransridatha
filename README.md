### Selected Engineering

* **Scholr 1.0**: Led the end-to-end infrastructure rollout for a cloud-native ERP platform supporting 1,200+ users. Enforced strict tenant isolation using rootless Podman and authored a custom Jenkins pipeline that achieved a 98.4% deployment success rate. `Podman` `Jenkins` `Linux VPS`
* **[FluxControl](https://github.com/saransridatha/fluxcontrol)**: Developed a serverless security middleware protecting backend infrastructure from application-layer attacks via adaptive rate limiting. Leveraged DynamoDB atomic counters for thread-safe operations during high-concurrency Lambda invocations. `AWS Lambda` `DynamoDB` `Python`
* **[DataStream](https://github.com/saransridatha/datastream)**: Architected a resilient data processing pipeline on Kubernetes, optimizing Apache Spark executor memory for stable throughput. Integrated Apache Flink for real-time stream processing to minimize end-to-end event latency. `Java` `Apache Spark` `Apache Flink` `Kubernetes`
* **[SkySafe](https://github.com/saransridatha/skysafe)**: Engineered a high-availability aviation risk intelligence platform. Designed a resilient multi-tiered caching architecture (LRU, SQLite, MongoDB) to mitigate upstream rate limits and maintain uptime during external API outages. `Next.js` `MongoDB`
* **[InfraPulse](https://github.com/saransridatha/InfraPulse)**: Built a highly concurrent, dependency-free health-check daemon in Go to monitor ICMP/TCP status across Linux servers with zero runtime overhead and automated SMTP alerting. `Go` `Daemon`
* **[httpTest](https://github.com/saransridatha/httpTest)**: CLI benchmarking tool for simulating concurrent distributed web traffic and performing deep API endpoint latency analysis. `Go` `CLI`
